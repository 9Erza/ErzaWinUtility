# ErzaWinUtility 🚀

ErzaWinUtility is a high-performance Windows optimization and management suite built with **WPF** and **.NET 10.0**. It is designed for power users who want full control over their operating system through a modern, clean interface.

> **Status:** ⚠️ Early Development Phase. Many features are being actively developed and tested.

---

## 🛠️ Current Features

The utility currently provides several core services to streamline Windows management:

### 🚀 Optimization
* **Erza Ultimate Power Plan**: One-click deployment of a custom power profile optimized for maximum performance and minimum system latency.

### ⚙️ System Configuration
* **Advanced Registry Tweaks**: Easily toggle detailed BSoD information, system hibernation, and restore point settings.
* **Interface Enhancements**: Quick toggles for showing hidden files, file extensions, and enabling seconds on the taskbar clock.
* **DNS Switcher**: Fast switching between major DNS providers (Cloudflare, Google, AdGuard, Quad9) with automatic cache flushing.

## ⚠️ Requirements
* **Operating System**: Windows 10 or Windows 11.
* **Permissions**: **Administrator Rights** are mandatory as the application modifies system-level registry keys and network settings.
* **Framework**: .NET 10.0 Runtime.
